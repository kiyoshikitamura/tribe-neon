# 次版・仕様判断依頼

以下は提案であり未FIX。承認前に運営設定や報酬へ反映しない。

|項目|提案|ユーザー判断による影響|
|---|---|---|
|Encounter発生|初回確定。以後30%。4回連続未遭遇なら5回目確定|低確率のまま未体験で離脱することを避ける。開催上限による見送りは外れ回数に数えない|
|難度|探索の級と独立して初級50%／中級35%／上級15%。本人が参加資格を満たす難度だけで比率を再配分|初心者は参加可能な初級、育成済みユーザーは下の探索級でも上級に遭遇可能|
|エリア・開催数|探索した街で発見。当日の通常Raid対象外の街も許可。自分が発見した開催中Encounterは1件まで。全体は既存の難度別上限を共用|日次対象外の街が恒久的にEncounter対象外となることを避け、強敵の過剰生成を防ぐ|
|追加報酬|通常報酬に加え、強化ドリンク・中／カスタムオイル・中を各1個（初級）、各2個（中級）、各3個（上級）|発見だけでは付与しない。既存ClearまたはRescueの受取資格を満たした人へ、1開催につき1回。両方達成しても追加分は重複しない|
|DIA内訳|円価格相当を有償、増量分を無償：300+0／500+0／1,000+30／2,000+80／5,000+240／10,000+680|確定済みの総数・価格は変えず、有償分だけ発行から120日を管理|
|DIA交換先|有償DIA由来のCASH・回復アイテムは元の失効日を引き継ぐ。無償由来は無期限。回復アイテム使用後のAP／BP／RPは消費済みとして期限を持ち込まない|混合支払時の配分・ロットを実装へ具体化する。期限を再起算しない。法的適合の判断済みという意味ではない|
|Special10連・既存Pt|追加保証・割引なし。既存Pt残高・履歴は保持|100Pt交換、SSR排出時リセットなし、Pt期限なしは既存正本の確定事項として維持|
|専用スキル台詞|全20スキルの短い戦闘用台詞を候補表で一括確認|モック台詞・ガチャ台詞を無断で正式採用しない|

専用装備の同一キャラ複数所持表示は、初版の正本対象が本人1種ずつのため今回の判断待ちにしない。目元素材の正規化・透過3件は制作側で進める。

## 実行環境に必要な対応

既存GitHub→Vercel自動Previewは動作している。直接配信のCLI認証・環境ファイルはこの作業環境にはない。
配信済み候補93c07a92の `/api/billing/config` はHTTP200 / available:false。現在の公開応答だけでは不足設定を特定できない。
Stripe Sandbox受入には、配信側で既存設定を秘密値を出さずに照合する必要がある：BILLING_MODE=sandbox、BILLING_SANDBOX_ENABLED、Preview Supabase URL／service_role、test key、Webhook署名secret、Preview戻り先。これは商品内容の仕様判断ではなく実行環境の確認。Production鍵・環境・aliasを変更しない。
