# クエスト21ステージ Balance v2 接続

基準：Quest 21Stage Balance Master v2 / Quest 21Boss Enemy Master（2026-09-17）。原本全シートを `source-extracted.json` に保存し、元ファイル名・SHA256を記録する。

- APは初級3・中級10・上級20、時間は5分・60分・180分。
- CASHは300・600・1,000、地元一致は基礎CASH+10%。
- Player EXPは街順に初級30/35/40/45/50/55/60、中級110/125/140/155/170/185/200、上級250/280/310/340/370/400/450。
- 通常CASH・EXP・周回アイテムは探索完了時。初回ボス報酬は指定券・素材のみで、仮設定の初回追加CASH・EXPは0にする。
- 周回ドロップ率はPreview候補。確率素材は既存どおり当選時1個、通常券は既存 `NORMAL_GACHA_TICKET_RANDOM` から3種等確率。地元一致は出現する確率枠に+2%ポイント、LUK非連動。
- 遭遇レイドは既存のアイテム倍化なしを維持し、撃破受給時に基礎CASH同額と基礎Player EXP50%を追加。端数は現行どおり切り捨て。保存済み遭遇ボーナス・受取済み履歴は変更しない。
- 初回券合計は通常3種各7、SP3種各15、指南書38、改造パーツ38。二重付与防止は既存ledgerを維持。
- 21ボス105体は指定HP/ATK/DEF/SPD・Level・Character ID・Skill IDを直接接続する。装備加算・倍率・推奨総合力からの自動生成を行わない。
- 未指定のLUK・覚醒・スキル強化値は既存Questの0を維持。発動ラウンド・効果は既存canonical Skillを使用する。
- `BURST_ATK` 等は既存戦闘AIの選択肢に存在しないため設計ラベルとして保持し、指定ステータス・スキル構成で街の違いを表す。戦闘AIは既存BALANCEDを維持し、新しいAI挙動は追加しない。
- 新しい敵編成は新規探索から適用。進行中探索・作成済みreplayは保存済み編成を保持する。未受取の通常報酬は現行Master参照方式を踏襲し、その地元CASH加算のみ整合させる。
- UIは周回目的を主表示、敵傾向を補助表示。詳細に推奨総合力・攻略ヒント・固定5人を表示し、報酬は共通アイコンと数量を使う。

## 検証と受入

- `quest_balance_v2_preview_rollback.sql`：指定QAの全21周回AP/時間/通常報酬、遭遇ボーナス計算、初回アイテム実付与合計、再受取で追加付与なしを確認。全変更rollback。
- `verify_quest_fixed_boss_master.mjs`：実SQLから生成した105体のスナップショットを正本と照合。
- 戦闘バランスは実エンジンで検証し、目標から外れても実装側で数値を変更しない。検証結果をバランス担当へ返す。
