## 2. Area Battle Grammar

- **新宿**: 高火力：ATK Buff→高倍率攻撃 / Counter: ATK Down・DEF Buff・Heal
- **渋谷**: 高速：SPD Buff＋Silence/Blind＋先制 / Counter: 耐久・SPD・早期撃破
- **池袋**: 鉄壁：全体DEF＋Heal / Counter: DEF Down・Burst
- **六本木**: Skill連携：ATK Buff＋ATK/DEF Down＋Heal / Counter: Buff/Debuff・Burst
- **秋葉原**: 妨害：Poison/Blind/Silence/Stun / Counter: 耐久・SPD・早期撃破
- **川崎**: 超火力：ATK Buff→280%/220%単体＋160%全体 / Counter: ATK Down・DEF Buff・SPD
- **横浜**: 持久：全体DEF＋Heal＋ATK Down＋決戦火力 / Counter: DEF Down・継続火力・Burst

## 4. Skill ID notation

表内 `026+021` は同一Enemy memberが `SKILL_026` と `SKILL_021` を持つ意味。`/` はSlot1〜5の区切り。

## 5. Difficulty Philosophy

- 初級: 総合力中心。Skill知識を要求しない。
- 中級: 2-skill/役割連携を認識できる。
- 上級: Buff/Debuff/Heal/状態異常/高倍率Attackの複数役割。
- 超級Raid: 5人Party全体が1つのBuildとして機能するEndgame。

## 6. Acceptance

- 新宿初級40kはTutorial後65〜75k帯で原則勝利。
- 中盤以降、推奨総合力未満でも適切なSkill構成で突破可能。
- Skill攻略目標は新宿90%→横浜50%まで段階的に広げる。保証値ではなくPreview Balance Target。
- 推奨総合力超過でもSkill相性が悪ければ敗北し得る。
- Questで学んだCounter Grammarが同Area Raidでも通用する。
- Raid EncounterはQuest進行に応じ 初級→中級→上級→超級。OptionalでQuest進行を止めない。
- Reward/CASH/EXP/LB/SP Ticketは変更しない。
- UIの敵傾向/攻略Hintは実Masterと一致させる。
- 実装側はMasterを裁量で自動スケールしない。Preview結果を報告しHuman Reviewで再FIX。
