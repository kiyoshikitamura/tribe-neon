# 初心者ガイド表示の共通規約

2026-09-17。クエスト進行・初敗北後の強化導線に適用。

- 案内は `GuideDialog`（`CanonicalDialog`＋アゲハの `TutorialNavigator`）へ統一。ページ先頭への案内カード・「初心者ガイド：」帯の追加は禁止する。
- タイトルは「初心者ガイド」。本文は次に行う操作と目的を短く記載し、ボタンは実際の操作名にする。初回クエスト入口のみ「まずはクエストを進めよう」を使う。
- ダイアログはページのスクロール領域外で表示する。小画面では本文のみスクロールし、操作ボタンはダイアログ下部に保持する。閉じた後は通常ページのガチャCTAまでスクロールできる。
- 初回クエスト入口以外は閉じられる。同じページに留まる間は再表示しない。ガチャ・キャラへ入り直すと該当段階の案内を再表示できる。再挑戦案内を閉じても行動を制限しない。
- 戦闘・ガチャ演出・結果表示・別ダイアログの途中には表示しない。先行するダイアログが閉じてから案内する。
- 初敗北後は未使用の無料ガチャをスキル→装備の順で案内する。対象カテゴリとノーマルタブを選択し、「ガチャへ」で案内を閉じて無料10連を操作する。抽選は案内ボタンから自動実行しない。
- 無料ガチャが使用済みならスキップする。「持ち物で進める」からも育成へ進め、課金を必須にしない。
- 装着操作の文言は「5人におまかせ装備・スキル」。Main Formationの出撃5人へ既存の一括推奨装着RPCで装備とスキルの両方を設定する。
- 装着後は「再度クエストに挑戦しよう」。戻り先は街一覧で、敗北済みボスは追加AP・探索待ちなしで再挑戦できる。
