# Raid レアリティ別編成・公開初期値の更新

2026-09-10。変更前: 1bf1bbe48909423430bd98a35216da9b19d44655。現行Edgeエンジンで今回の28編成を新たに測定。旧監査Damageの流用なし。ローカル候補のみ。

## 編成方針と検証

初級 N3/R2、中級 R3/N1/SR1、上級 SR3/R2、超級 SSR3/SR2。同じエリアの20枠はすべて異なるキャラ。全28組でメンバー集合が異なり、全60キャラを使用する。エリア間の再登場はある。出身地と出番の偏りを考慮し、他エリアから不足枠を補完。パーティ名称は維持。

装備42種・育成値・レイド専用ATK/DEF/SPD/LUK・汎用スキルの役割は前候補を維持。入れ替えたキャラに旧キャラ専用スキルを持たせないよう、該当枠のみ本人の有効スキルに交換、対象がなければ除外。最大HP参照の回復・シールド・継続回復は専用枠に追加しない。最終構成のスキルは30種。

## 残る偏りと範囲

- 全seedでプレイヤー5人が行動。初級は18〜21roundで全滅するが、早期行動不能は確認されなかった。
- 秋葉原上級の平均Damageは中級の約65%で、敵スキルによる全滅が残る。HPを5,700,000に合わせ、標準参加の必要戦数は18戦。全難度のDamage単調増加は満たしていない。
- 渋谷超級等にはseedによるDamage幅が残る。3〜6seedは公開初期値の点検であり確率保証ではない。
- 30round到達が多いが、設定上限を超える戦闘はない。Replayの体感所要時間は今回の範囲外。
- 現候補にはRaid Instance本人属性×2・Guild×2の接続がなく、現在のCanonical個体相性を使用。Replay/Formula変更禁止を守り倍率の代入はしていない。倍率接続時にはHP再評価が必要。
- 共有マスター、計算エンジン、Replay、報酬・参加制限は変更なし。外部DB適用・Deploy・公開は行わない。
