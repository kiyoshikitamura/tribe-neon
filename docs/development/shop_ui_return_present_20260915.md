# ショップUI・購入復帰・プレゼント受取改修（2026-09-15）

## 基準

ユーザーよりPreview決済検証完了の報告を受領。本変更後のStripe→iPhoneショップ復帰は追加確認対象。
PC側の7850cf6（サーバー運営状態を使うショップ遷移修正）を取り込んで実装。
対象はPreviewのみ。Production配信・DB変更・Migration再適用・Stripe設定変更なし。

## 変更

- スペシャルショップ／ダイヤショップのタブと文字サイズを整理。
- パックはビギナー→育成応援→覚醒応援→チケット→ダイヤの順。
- パック内容はコンパクトな連続テキスト。ダイヤ・交換商品は商品情報＋右側購入CTA、内訳全文を保持。
- 表示上のダイアをダイヤへ統一。購入履歴・購入分の有効期限は小ボタンからダイアログを開き、その時点で取得。
- ショップcomponentと購入設定をフッター表示後・pointer/focusで先読み。公開configは成功時30秒だけ共有し重複リクエストを抑止。購入APIの価格/回数/運営状態チェックは維持。
- 既存Stripe戻り先 /billing/return?order= を /?billing_order= へ転送。サーバー認証済みゲームのショップに購入状況ダイアログを重ねる。閉じるはquery除去＋ショップ維持。
- 購入確定はrestoreのサーバー応答のみ。GRANTED/PENDING/EXPIREDと失敗を区別。履歴再取得の失敗で確定済み購入を失敗表示に変えない。
- プレゼント受取後は全bootstrapを待たず、残高・所持品・プレゼント・装備を並列再取得。所有者切替guard、二重受取lock、成功/投影失敗の区別を保持。
- プレゼントBOX・お知らせのFullScreenPanel最下部閉じるを中央配置。

価格・付与数量・購入上限・有償/無償・120日期限は変更しない。
