# 第19工程 Guild貢献参照の照合

2026-09-08。基準 `5243b287f3e3261bd587a736cabc70af528f9dc7`。親によるRepository参照確認。既存監査の再開や表示仕様の新規FIXではない。

|参照先|現在の実装|Roomとの接続|
|---|---|---|
|おすすめGuild（SQL186の最終get_recommended_guilds）|ログ所属で直近7日のraw合計/参加ユーザー数を算出し、おすすめ順の要素にする|Instanceの日次キーによる制限がなく、新Roomログも参照対象|
|公開Guild詳細（SQL204のget_public_guild_detail）|ログ所属で直近7日のraw合計を表示用に返す|同じく新Roomログが対象|
|Room確定（SQL256）|開始ReplayのguildIdSnapshotをDamageログのguild_idへ保存|移籍後の現在所属に過去ログを付け替えない|

SQL261はレイド順位と順位報酬の新規生成を廃止するが、上記のGuild紹介用参照は撤去しない。この貢献参照は順位報酬の復活ではない。Room内参加者の現在所属/戦闘時所属も別項目として維持される。

参照はログのcreated_atから7日間、raw合計を使う。終了後確定の保存rawも含み、討伐報酬のACTIVE中確定のみという条件とは異なる。現在所属ユーザーの合算ではなく、各戦闘の所属Snapshotへの帰属となる。

この照合で、上記2読者にRoomを含めるためだけのSQL変更は不要と確認した。おすすめ順の重みや所属基準を変更する判断はしていない。数値・履歴・既存関数を変更せず、実DB/実機の表示確認は残す。
