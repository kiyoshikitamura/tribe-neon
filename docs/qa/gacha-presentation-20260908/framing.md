# ガチャ立ち絵のフレーミング統一

SSR固有の1.4倍拡大とobject-fit:coverによる端末比率依存を撤去。全レアリティで、頭頂から全身高の70%（膝上目安）までを表示する。立ち絵領域と説明領域を分け、セリフで身体が隠れる範囲の差も抑える。下端は背景へフェード。

gachaStandingBounds.jsonは既存60枚のPNGのアルファ値16以上の外接矩形から生成した表示専用データ。横中心・頭頂・全身高で透過余白を補正し、2%の頭上余白を確保する。ポーズ・体格は元の立ち絵を維持。新しい立ち絵を追加・差し替えた際は同データも更新する。

検証: Preview設定のビルド、ESLint。390×844・320×568でN/R/SR/SSR計6体（レイジ、ダイモン、ルーカス、ダイスケ、ゲンジ、ミヤビ）の詳細を開き、同じ身体範囲の表示と操作を確認。実機Safariはユーザー確認待ち。
