# ガチャ書体比較

2026-09-08。QAシナリオ gacha-character-v3 に font=zero / tetsubin / torono を指定。
通常は街名・キャラ名・一覧見出しに適用。fontScope=all を追加するとセリフにも適用する。
未指定では既存書体を維持。本番採用は未確定。

- 零ゴシック: 利用者提供公式ZIP。比較WOFF2 140,168 bytes。
- 鉄瓶ゴシック: 利用者提供公式ZIP。比較WOFF2 112,528 bytes。
- 瀞ノグリッチ黒体 H1: 作者公式GitHubから取得。比較WOFF2 95,892 bytes。

ライセンス・著作権・加工内容は public/fonts/gacha-comparison/NOTICE.md に記載。
選択した1書体だけを取得し、フォント準備後にガチャ演出をマウントする。

検証: Previewビルド成功。3書体それぞれについて、読み込み完了、街紹介後のTAP、一覧からキャラ詳細、実際の適用family、フォントリクエスト1件を確認。
日本語システムフォントのない検証環境では比較対象外の補助文字が欠字となるため、端末標準書体を使う補助文字の実機確認は別途必要。
