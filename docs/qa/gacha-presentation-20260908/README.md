# キャラクターガチャ演出 v3

2026-09-08。基準: codex/kpi-dashboard-production-20260904 / b08e396。

1体ごとのロゴ画面と入力待ち時間を取り除き、確定済みの獲得結果を連続して紹介する。

- 黒金のカード裏面を実際の抽選件数だけ扇状に配置。確定結果の最高レアリティから銀／紫／金の光を選ぶ。金の期待演出は実際にSSRがある場合のみ。
- N/Rは登場と同時にセリフを全文表示、SRはフェード、SSRはセリフの文字送り・短い間・登場の順。SSR文字送りはタップで全文表示できる。
- 登場中のタップで表示完了、次のタップで次へ。短時間の二重入力を抑止。SKIPは全結果一覧へ移動し、残った演出タイマーを解除。
- 10連は5列2行。実際の順番・名前・レアリティ・NEW／覚醒進捗を表示し、カードをタップすると再確認できる。
- チュートリアルの結果一覧に「この仲間たちでチームを組もう」「編成へ進む」。通常ガチャは「ガチャへ戻る」。
- 全60体のガチャセリフに対応。SSR10体は既存確定マスタを参照し、追加50体は2026-09-08マスタに確定文言を収録。ホームは既存SSR10体のまま。
- 抽選RPC、確率、消費、取得順序、報酬計算、サーバーのチュートリアル進行は変更しない。スキル／装備ガチャの既存表示を維持。

- preview設定のNext.js本番ビルド、TypeScript検査に成功。

- 全60体セリフ、既存SSR10体、ホームセリフ、7出身地背景、Phase 6-B契約チェック成功。
- Playwright 12件成功: 390×844／320×568、5列2行と順番、詳細から戻る、チュートリアルCTA、再実行、SSR全文タップとスキップ後のタイマー解除、連打、N/R/SRの連続表示、動きを減らす設定、キーボードのフォーカス循環、スキル／装備の抽選中表示、エラー復帰、抽選二重実行防止、キャラ1回／10回。
- Chromiumで開封・一覧・SSRのスクリーンショットを確認。実行時JavaScriptエラーと表示画像の欠落は0。撮影環境に日本語フォントがないため撮影時のみNoto Sans JPを追加。アプリ依存関係への追加なし。
