# バトル前後3画面モック

URL: `/qa/battle-flow-v3`

## 対象と境界

- 出撃準備、VS／開始演出、Resultの独立したQAモック。
- FIX済みのガチャ・バトル演出は変更しない。既存ゲーム画面への組み込みは未実施。
- 認証・バトルAPI・報酬付与・チュートリアル進捗更新を呼ばない。本番では既存QA公開制御により非公開。
- レイド固有UIは対象外。

## 出撃準備

- リーダー対面、総合力、味方5人、属性・レアリティ、作戦、開始ボタン。
- 敵編成は折りたたみ。総合力は比較用の固定値。
- チュートリアル／通常戦を切り替えて作戦変更UIを確認できる。切り替えはモック内のみ。

## VS

- 既存の立ち絵と新宿背景を使用。1.6秒の表示時間を確保。
- バトルは省略し、表示時間終了後にResult比較へ移動できる。
- FIX済みバトル演出は別タブへのリンクで確認する。連続統合済みとは扱わない。

## Result

- 勝利／敗北／報酬確定待ちを切り替える。
- 固定リプレイを既存 `analyzeBattleResult` に渡し、与ダメージ・撃破・回復・シールド・生存による既存MVP採点を使用。
- 勝利例はレイジ、敗北例は回復・支援貢献のあるカエデが選ばれる。MVPをUIで固定指定しない。
- 勝敗→MVP→代表戦績→報酬→次へ。詳細スコアと敵味方比較は開閉式。
- セリフは既存ガチャ文言の仮配置であり、Result専用文言としての承認は未実施。
- 報酬待ちでは次へ無効。確定模擬ボタンで解除する。確定報酬はCASH1,200、XP240の表示サンプル。
- 次へ／編成確認は接続予定を表示するだけ。実ゲームへの遷移・育成変更はしない。

## 素材

既存の立ち絵・背景・属性・レアリティ・CASH画像を再利用。キャラ画像は描き起こさない。
鉄瓶ゴシックは別のサブセット `/effects/battle-flow-v3/tetsubin.woff2` を作成し、FIX済み演出のフォントを変更しない。元ライセンスは `public/fonts/gacha-comparison/Apache-2.0.txt` を維持。
必要画像の読み込み・decodeとフォント準備を待って表示。失敗時は再試行可能。

## 後続

実機で3画面を確認・FIXした後、既存の準備処理・MVP集計・報酬確定・チュートリアル完了処理へ接続する。今回のモックは統合済みではない。
ガチャとバトルの本番同時反映方針を維持する。
